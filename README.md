## 📚 题库概况

- **题目总数：1251 道**
- **单选题：398 道**
- **多选题：168 道**
- **判断题：685 道**
- 主要涵盖实验室安全、化学安全、生物医学及生物安全、消防安全、辐射防护与特种设备安全等知识点。
- 包含题目和正确答案；部分题目没有文字解析。

## 📝 使用说明

1. 大多数同学建议下载 **Excel 版本**：可以直接打开、搜索关键词、按照题型或知识点筛选。
2. **JSON 版本** 适合编程、制作本地刷题工具等用途。
3. 本题库用于辅助复习，**不能替代学校平台规定的学习时长**，也不保证正式考试只从这些题目中抽题。

如发现题目或整理格式有问题，欢迎通过仓库的 Issues 提出反馈。
