## 🛠️ 题库导出脚本

当时整理题库使用的浏览器脚本已开源：**[查看题库导出脚本（JavaScript）](./scripts/export_question_bank.js)**。

这是从**正常登录后可访问的题库预览页面**读取题目及答案、保存为 JSON 的辅助工具，不是考试自动答题工具。

简单使用方法：

1. 使用 Chrome 或 Edge 正常登录学校的实验室安全平台，并打开题库预览页面。
2. 按 `F12`（Mac 可通过浏览器菜单进入开发者工具），在题库页面点击一次「查询」。
3. 在开发者工具的 **Sources → Snippets** 中新建片段，复制 [`export_question_bank.js`](./scripts/export_question_bank.js) 的内容运行。
4. 先将脚本中的 `LIMIT` 改为 `10` 测试；确认正常后再按需设置导出数量。运行时保持页面打开，完成后自动下载 JSON。

> 注意：仅限使用本人有权限查看的题库内容，遵守学校规定；不要分享账号、密码、Cookie 或浏览器请求头。批量读取会产生较多请求，请勿频繁运行。平台接口可能更新，脚本不保证长期有效。实际学习时长仍须按规定完成。

## 📝 使用说明

本题库用于辅助复习，**不能替代学校平台规定的学习时长**，也不保证正式考试只从这些题目中抽题。
